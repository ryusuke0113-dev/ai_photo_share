# 画面設計書

`docs/requirements.md` の内容を前提とした画面設計です。

## 1. 画面一覧

| ID | 画面名 | 目的 | URL | ログイン | テンプレート |
| --- | --- | --- | --- | --- | --- |
| S-01 | 投稿一覧（トップ） | みんなの投稿を新しい順に見る | `/` | 不要 | `index.html` |
| S-02 | 投稿詳細 | 1件の投稿を見る。削除・いいねを行う | `/posts/<id>` | 不要 | `post_detail.html` |
| S-03 | 投稿作成 | 写真とキャプションを投稿する | `/posts/new` | **必要** | `post_new.html` |
| S-04 | ユーザー登録 | 新しくアカウントを作る | `/register` | 不要 | `register.html` |
| S-05 | ログイン | ログインして投稿できる状態にする | `/login` | 不要 | `login.html` |

すべての画面は共通レイアウト `base.html` を継承します。

## 2. 共通レイアウト（base.html）

全画面で共通して表示する部分です。

| 部品 | 内容 |
| --- | --- |
| ヘッダー | アプリ名（クリックで投稿一覧へ） |
| メニュー（未ログイン時） | 「登録」「ログイン」 |
| メニュー（ログイン中） | 表示名、「投稿する」「ログアウト」 |
| メッセージ表示欄 | 成功・エラーのメッセージ（Flask の `flash`）を表示する |

## 3. 各画面の詳細

### S-01 投稿一覧（トップ）

- 目的: すべての投稿を、インスタグラムのホームのように縦に1件ずつ並べて見る
- ログイン: 不要
- 表示する項目（1件ごと）
  - 写真
  - キャプション
  - 投稿者の表示名
  - 投稿日時
- 並び順: 新しい投稿が上
- 操作
  - 写真をクリック → 投稿詳細（S-02）へ
- 投稿が0件のとき: 「まだ投稿がありません」と表示する

### S-02 投稿詳細

- 目的: 1件の投稿を大きく表示し、削除やいいねを行う
- ログイン: 不要（削除・いいねの操作のみログインが必要）
- 表示する項目
  - 写真
  - キャプション
  - 投稿者の表示名
  - 投稿日時
  - いいね数（余裕があれば）
- 操作
  - 「削除」ボタン: 自分の投稿のときだけ表示する → 削除後は投稿一覧（S-01）へ
  - 「いいね」ボタン（余裕があれば）: ログイン中のみ押せる → 押した後は同じ投稿詳細を再表示
  - 「一覧へ戻る」リンク → 投稿一覧（S-01）へ
- 存在しない投稿の場合: 404 エラーを表示する

### S-03 投稿作成

- 目的: 写真1枚と短いキャプションを投稿する
- ログイン: **必要**（未ログインならログイン画面へ移動させる）
- 入力項目
  - 写真ファイル（JPG・PNG、5MB まで）
  - キャプション（140 文字まで）
- 操作
  - 「投稿する」ボタン → 成功したら投稿一覧（S-01）へ
- エラー時: 同じ画面にエラーメッセージを表示する
  - 写真が選ばれていない
  - JPG・PNG 以外のファイル
  - 5MB を超えるファイル
  - キャプションが 140 文字を超えている

### S-04 ユーザー登録

- 目的: 新しくアカウントを作る
- ログイン: 不要
- 入力項目
  - メールアドレス
  - 表示名
  - パスワード
- 操作
  - 「登録する」ボタン → 成功したらログイン画面（S-05）へ
  - 「ログインはこちら」リンク → ログイン画面（S-05）へ
- エラー時: 同じ画面にエラーメッセージを表示する
  - 未入力の項目がある
  - メールアドレスが登録済み

### S-05 ログイン

- 目的: ログインして投稿できる状態にする
- ログイン: 不要
- 入力項目
  - メールアドレス
  - パスワード
- 操作
  - 「ログイン」ボタン → 成功したら投稿一覧（S-01）へ
  - 「新規登録はこちら」リンク → ユーザー登録画面（S-04）へ
- エラー時: 同じ画面に「メールアドレスまたはパスワードが違います」と表示する

## 4. 画面遷移

| 遷移元 | 操作 | 遷移先 | 備考 |
| --- | --- | --- | --- |
| 投稿一覧 | 写真をクリック | 投稿詳細 | |
| 投稿一覧 | メニューの「投稿する」 | 投稿作成 | ログイン中のみメニューに表示 |
| 投稿詳細 | 「削除」 | 投稿一覧 | 自分の投稿のみ |
| 投稿詳細 | 「いいね」 | 投稿詳細 | 余裕があれば |
| 投稿詳細 | 「一覧へ戻る」 | 投稿一覧 | |
| 投稿作成 | 投稿に成功 | 投稿一覧 | |
| ユーザー登録 | 登録に成功 | ログイン | |
| ログイン | ログインに成功 | 投稿一覧 | |
| 全画面 | メニューの「ログアウト」 | 投稿一覧 | |
| （未ログイン） | 投稿作成の URL にアクセス | ログイン | ログイン後は投稿一覧へ移る |

### 遷移の流れ（まとめ）

- ユーザー登録 → ログイン → 投稿一覧
- 投稿一覧 → 投稿詳細 → （削除）→ 投稿一覧
- 投稿一覧 → 投稿作成 → （投稿）→ 投稿一覧

## 5. テンプレート構成

- `templates/`
  - `base.html`（共通レイアウト）
  - `index.html`（S-01 投稿一覧）
  - `post_detail.html`（S-02 投稿詳細）
  - `post_new.html`（S-03 投稿作成）
  - `register.html`（S-04 ユーザー登録）
  - `login.html`（S-05 ログイン）
